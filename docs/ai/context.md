# Contexto del proyecto

Sistema de gestión para una tienda de ropa y personalización, dirigido a dueños y empleados.

## Módulos previstos

- Acceso de usuarios
- Inventario
- Servicios de personalización
- CRM y clientes

## Stack y arquitectura

- Blazor y ASP.NET Core sobre .NET 10
- PostgreSQL con EF Core Code First
- Monolito modular; organizar el trabajo futuro por vertical slices dentro de cada feature

El alcance funcional está definido inicialmente en `minimal-prd.md`. Las páginas actuales son solo puntos de entrada para la navegación.
