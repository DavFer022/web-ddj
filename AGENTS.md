# Instrucciones del proyecto

- Mantener la solución como monolito modular, organizando el código por módulo/feature.
- Usar Blazor y ASP.NET Core sobre .NET 10.
- Usar EF Core Code First con PostgreSQL (Npgsql).
- No guardar contraseñas, cadenas de conexión reales ni otros secretos en archivos versionados.
- Consultar `minimal-prd.md` y `docs/ai/` para el contexto del producto.
- Mantener los cambios iniciales sencillos y evitar implementar funcionalidades fuera del alcance solicitado.
